# ⚡ EcoPulse EV - Smart EV Charging & Load Balancing System

> **Smart India Hackathon (SIH) Internal Hackathon Project**  
> Developed by **Team BIOPULSE** 🚗⚡

## 📌 Problem Statement
**(Software) EV Charging Station Locator and Slot Booking App with Load-Balancing Suggestions**

With the rapid adoption of Electric Vehicles (EVs), charging infrastructure often faces severe congestion at popular hubs, while nearby stations remain underutilized. **EcoPulse EV** solves this by offering an interactive map locator, seamless slot booking, and a dynamic **Smart Load-Balancing Engine** that intelligently reroutes drivers to less crowded stations.

## ✨ Core Features

* 🗺️ **Interactive EV Station Map:** Real-time visual map showcasing nearby EV charging hubs with charger types (Fast, Slow, Type 2, CCS).
* 🔐 **User Authentication:** Secure signup and login for EV drivers to manage reservations.
* 📅 **Real-Time Slot Booking:** Select specific chargers and reserve dedicated time windows without conflict.
* ⚖️ **Smart Load-Balancing Engine (Winning Feature):** Detects station congestion and suggests alternative stations nearby with wait-time reductions or incentives.
* 📊 **Station Operator Dashboard:** Admin view for EV station managers to monitor charger availability and grid load metrics.

## 🛠️ Tech Stack

* **Frontend:** React.js, HTML5, CSS3 🎨
* **Backend:** Node.js, Express.js ⚙️
* **Database:** MongoDB Atlas / Supabase 🗄️
* **Mapping API:** Leaflet.js + OpenStreetMap 🗺️
* **Hosting:** Vercel / Netlify (Frontend), Render (Backend) 🚀
